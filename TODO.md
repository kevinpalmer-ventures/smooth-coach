# Smooth Coach — Delivery Checklist

- [x] **Source-based 10-day program:** Presents all 10 days from the attached Green Smoothie Cleanse document with the daily recipe, ingredients, quantities, blend instructions, serving guidance, snack options, water target, and foods/drinks to avoid.
- [x] **Today coaching screen:** Shows the current day’s smoothie, ordered preparation and meal actions, useful source guidance, a water tracker, an optional daily reflection, and the next recommended step.
- [x] **Completion and progress:** Lets the user complete daily actions, record how the day went, view completed days and the next recommended day, and keeps that progress in the browser.
- [x] **Program, recipes, and prep:** Provides mobile-friendly navigation between Today, the 10-day program, individual recipe/preparation details, and shopping/prep guidance grouped by phase or relevant days.
- [x] **Coaching tone and reminders:** Surfaces concise encouragement and source-aligned tips at useful moments, and offers a clearly explained browser notification opt-in for active/open-tab routine nudges.
- [x] **Safety context:** Clearly identifies the app as an organizer for supplied source material rather than medical advice; it does not turn the document’s colon-cleansing or bowel-movement claims into instructions.
- [x] **Responsive presentation:** Delivers a mobile- and desktop-ready Soft Orchard Ritual interface, verified by 1280px and 375px preview captures.
- [x] **Personal accounts:** Allows a user to sign in with Google or another OpenID Connect provider, establishes a validated application session, shows account status, and keeps signed-in coaching state private to that account.
- [x] **Weight progression:** Allows each signed-in user to add or update a dated weight in lb or kg, view their own chronological entries, and see a private progression graph, summary, and recent history.
- [x] **Progression pictures:** Allows each signed-in user to securely upload a dated JPEG, PNG, or WebP progression picture with an optional caption, and see it only in their own private visual timeline.
